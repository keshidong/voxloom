# 切片 1：纯 Whisper 音频转写模块

日期：2026-11-20。状态：规范 PCM/WAV → 本地 Whisper → 原语言文本的 Swift API 与 CLI 已实现，单元、模块、真实模型短录音 E2E 已通过。麦克风、Watch、系统输入法、Qwen 纠错和整机资源验收不在本切片完成范围内。

## 模块与契约

| 层 / 模块 | 已实现契约 |
|---|---|
| 基础 / Audio | 16kHz、单声道、PCM16；最长 60 秒；纯 WAV 编解码；最大文件 2,000,000 字节 |
| 基础 / Recognition | 识别选项、原始文本和有类型的错误；`auto/zh/en`；不依赖推理引擎 |
| 基础 / CLI | 参数解析为值；不执行 IO，不解释 shell 字符 |
| 业务 / Recognition | `SpeechRecognizer.transcribe(_:options:) async throws -> Transcript`；可替换实现 |
| 业务 / Whisper | 显式本地引擎/权重；不下载、不回退云端；最多一个请求；超时、取消、错误清理 |
| 业务 / Process | 仅管理本请求拥有的子进程；启动错误、退出码、取消与回收；有界超时 |
| 业务 / CommandLine | WAV → JSON/文字；成功 0、参数/识别错误 2、中断 130；Ctrl-C/SIGTERM 清理 |

测试就近维护在各模块 `Tests/` 下，专属 fixtures 同目录归属；不需要根目录 `tests/`。纯函数与单次异步转写未引入 Rx，后续交错交互再按语言采用 Rx*。

## TDD 与修复记录

- WAV 编码、时长限制、解码、Whisper 转写、进程适配、超时及首个 CLI 转写用例经历了行为失败 → 实现 → 测试通过；初始空输出或不可用引擎实现不满足对应契约。
- 首次 SwiftPM 缓存权限和 CLT 的 Swift Testing 链接问题属于环境失败，不计作 RED。已用工作区缓存和检测到的工具链 framework 路径解决。
- 部分值模型、参数解析及补充畸形 WAV 用例作为已有行为的回归验证；未把它们起初通过或编译失败写成有效 RED。
- SIGINT/SIGTERM 测试暴露 CLI 以信号 5 崩溃，子进程和临时音频未清理。崩溃记录指向继承 MainActor 的信号回调在后台队列执行；将回调明确标为 `@Sendable` 后，两种中断均返回 130，子进程已回收、临时目录已删除。

## 真实 Whisper 验证

命令：`python3 scripts/smoke-whisper.py`，退出 0。2 个 Swift API/CLI E2E 测试通过，另有以下 4 个真实 CLI 场景通过，缺资源时脚本直接失败，不把跳过计作成功。详细输出见 `../.build/reports/e2e-swift.log` 和 `e2e.json`。

| 模型 / 场景 | 输入 / 断言 | 结果 | 本轮耗时 |
|---|---|---|---:|
| tiny / 英文 | JFK，原语言为 en，包含 ask / country | 通过 | 0.378 秒 |
| large-v3-turbo Q5 / 英文 | 同一英文录音，模型替换后契约一致 | 通过 | 5.174 秒 |
| large-v3-turbo Q5 / 中文 | 约 4.20 秒中文，含“交易”“停滞”，语言 zh | 通过 | 5.048 秒 |
| large-v3-turbo Q5 / 自动检测中文 | 同一录音，auto 检测为 zh | 通过 | 9.926 秒 |

上述为 CPU、4 线程、逐次新进程、单次公开短样本；系统文件缓存未清理。仅为执行记录，不是延迟基准、p50/p95 或识别准确率。中文转写为“甚至出现交易几乎停滞的情况”，仅未附句号；样本及参考文本来自 [Qwen3-ASR 官方示例](https://github.com/QwenLM/Qwen3-ASR#forcedaligner-usage)。英文样本来自 [whisper.cpp v1.8.2](https://github.com/ggml-org/whisper.cpp/tree/v1.8.2/samples)。没有使用 Qwen 模型进行本轮识别。

资源：whisper.cpp v1.8.2，tiny SHA1 `bd577a113a864445d4c299885e0cb97d4ba92b5f`，Turbo Q5 SHA1 `e050f7970618a659205450ad97eb95a18d69c9ee`。真实 E2E 脚本同时校验录音 SHA256，避免样本意外变动。

## 已知限制与后续

- 当前环境 GPU 路径原生引擎以信号 11 退出；CPU 路径通过。尚未定位 GPU 崩溃原因，不能宣称 Metal 加速已验收。
- 引擎按请求加载模型，尚无常驻、流式部分结果或音频采集；后续适配可继续实现同一 `SpeechRecognizer` 契约。
- 已验证本地资源路径运行，未执行整机主动断网重启、联网行为抓包或全设备输入链路验收。
- 中英混说、轻声、噪声、数字/术语及 CER/WER 需要专门录音集；当前短样本不提供识别率结论。
- 尚未接入 Qwen3-4B；它作为独立文本纠错接口组合在原始转写之后，不混入 STT 的模型配置。
- 16GB 设备、进程树峰值 ≤8GB、长输入/连续多轮资源和能耗尚待实测，当前未作运行内存保证。
